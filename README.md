# Employee Debt Tracker

A simple and modern web application for tracking employee debts (utang) in the office.

Built with **HTML**, **CSS**, **JavaScript**, and **Firebase Firestore**.

---

## Features

- Add, Edit, and Delete employee debts
- Record partial or full payments
- Automatic status (Pending / Partial / Paid)
- Payment history log
- Search and filter by status
- Export data to CSV (Excel-compatible format)
- Print individual employee receipts (¼ paper size)
- Select employee to print from dropdown
- Dark / Light theme toggle
- Real-time database using Firebase
- Glassmorphism UI design

---

## Tech Stack

- HTML5
- CSS3 (Glassmorphism + Responsive)
- Vanilla JavaScript
- Firebase Firestore (Realtime Database)

---

## How to Use

1. **Add New Debt**  
   Fill in the employee name, amount, date, Order Slip #, and remarks.

2. **Record Payment**  
   Click the **Pay** button and enter the amount paid.

3. **Print Receipt**  
   - Click the **Print** button on each row, or  
   - Use the top **Print Receipt** button and select an employee.

4. **Export Data**  
   Click **Export CSV** to download the data in Excel format.
